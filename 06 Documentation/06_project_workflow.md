# Project Workflow

## End-to-End Data Analytics Workflow

This project follows a structured end-to-end Data Analytics lifecycle, beginning with a relational SQLite database and ending with a business dashboard and project documentation.

---

## Workflow

SQLite Database

↓

Python

- Load Data
- Data Understanding
- Data Cleaning
- Data Validation
- Exploratory Data Analysis (EDA)

↓

Export Cleaned CSV Files

↓

SQL

- Data Import
- Business Analysis
- Joins
- Aggregate Functions
- Window Functions
- Common Table Expressions (CTEs)
- Views

↓

Power BI

- Data Modeling
- DAX Measures
- KPI Cards
- Interactive Dashboard
- Business Insights

↓

Business Report

↓

GitHub Documentation

↓

LinkedIn Project Showcase
