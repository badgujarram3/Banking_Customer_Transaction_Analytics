# Banking Customer & Transaction Analytics

## Project Overview

This project focuses on analyzing banking customer behaviour, financial transactions, account performance, loan portfolio, and credit risk patterns.

The objective is to generate actionable insights that help banking stakeholders improve customer engagement, risk management, and business decisions.

## Data Source

The dataset is provided as a relational banking database.

Data sources:

| Source | Purpose |
|-|-|
| SQLite Database | Primary data source containing all tables |
| SQL Script | Database schema and row-level data insertion queries |
| CSV Files | Supporting table extracts |

The database contains multiple relational tables used for analytics.
